# Cut Trainer

A billiards cut-shot aim trainer. Read the shot, call the fraction (full, ¾, ½, ¼, ⅛), see where it goes.

- **Trainer:** `index.html`, a single self-contained page. Scores and settings stay in your browser.
- **Live (AR):** `ar.html`. Pin the table by tapping three corner pockets, then tap the balls (found in the camera picture) and the pocket, call the fraction, and see the ghost ball and paths on the real table. Needs Chrome on an Android phone with Google Play Services for AR. Add `?debug` to see what the ball finder saw.

Hosted with GitHub Pages: https://jeanluclariviere.github.io/CutTrainer/

It installs as an app (Chrome menu → Install app / Add to Home screen) and works offline.
